## 🚀 Key Features

1. **Curated Loan Portfolios:** Categorized cards for Personal, Home, and Education loans with live interest rate benchmarks and features.
2. **Interactive EMI Estimator:** Implements standard financial compounding logic `E = [P × r × (1+r)^n] / [(1+r)^n – 1]` with responsive sliders and a dynamic principal-to-interest visual breakdown bar.
3. **Application Intake:** Validated form with automatic issuance of randomized reference numbers (e.g. `LL-2025-XXXX`).
4. **Reference Status Engine:** Instant query mechanism to retrieve approval progress and stored applicant records.
5. **Human-Crafted Responsive Design:** Polished typography and styling optimized for mobile and desktop viewports.
